AX650 GStreamer 运行时

预编译的 GStreamer 1.22.12 + WebRTC 推流组件，一条命令装到板子上，无需交叉编译工具链。

aarch64 glibc 2.30+ 兼容层内置 含 whip_push 约 16 MB

1板端一键安装

以 root 在开发板上执行。install.sh 会自动选最新版本、校验 SHA256、解压到 /usr/local、写好环境变量并自检。

curl -fsSL …/install.sh | sh

装完后当前 shell 立即生效：

. /etc/profile.d/gstreamer.sh
gst-inspect-1.0 webrtcbin

3安装前确认

  • 架构必须是 aarch64（uname -m 查看），x86 板子用不了
  • 板子 glibc ≥ 2.30；低版本由 libglibc230_compat.so 兜底
  • /usr/local 至少留 40 MB 空间
  • 替换前先停推流：killall whip_push（脚本检测到会拒绝执行，可加 --force）
  • 仅体检不安装：sh install.sh --check

4其他用法

# 指定版本
curl -fsSL …/install.sh | sh -s -- -v 1.22.12-r20261110

# 内网镜像（改源地址）
GST_BASE=http://192.168.1.10/gst sh install.sh

# 离线：先把包 scp 到板子，再本地安装
sh install.sh -f /tmp/gstreamer-aarch64-deploy.tar.gz

卸载：删除 /usr/local/{bin/whip_push, lib/gstreamer-1.0, libexec/gstreamer-1.0} 与 /etc/profile.d/gstreamer.sh 即可，不写系统其他位置。
